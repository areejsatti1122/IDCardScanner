# IDCardScanner

An Android application that scans and extracts information from ID cards using Google ML Kit Text Recognition.

## Features
- **Real-time OCR**: Scan ID cards using device camera
- **Text Extraction**: Extract name, ID number, DOB, and other fields
- **Built with**: Kotlin, CameraX, Jetpack Compose, ML Kit
- **Fast Processing**: On-device text recognition, no internet required

## Tech Stack
`Kotlin` `Android Studio` `ML Kit` `CameraX` `Jetpack Compose` `Gradle 9.5.0`
